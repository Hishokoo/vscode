# 05111 → 05112 修改指令

以 `05111trytrain_mujoco_td3.py` 為基底，產生 `05112trytrain_mujoco_td3.py`，套用以下三項修改：

---

## 修改一：q_pos 係數調整

將 `step()` 方法中 `q_pos` 的係數從 `1.0` 改為 `3.0`：

```python
# 改前
q_pos = 1.0 * (cart_pos ** 2)

# 改後
q_pos = 3.0 * (cart_pos ** 2)
```

---

## 修改二：Settling_Time 門檻收緊

將 `step()` 方法中判斷穩定時間的角度門檻從 `0.02` 改為 `0.01`：

```python
# 改前
if self.metric_settling_time is None and abs(pole_angle) < 0.02:

# 改後
if self.metric_settling_time is None and abs(pole_angle) < 0.01:
```

---

## 修改三：新增正規化指標

在 `_compute_episode_metrics()` 方法中，於原有 ISE / IAE / ITAE 之後新增三個每步正規化版本：

```python
"ISE_per_step":  float(np.sum(angles ** 2) / max(n, 1)),
"IAE_per_step":  float(np.sum(np.abs(angles)) / max(n, 1)),
"ITAE_per_step": float(np.sum(np.arange(1, n + 1) * np.abs(angles)) / max(n, 1)),
```

同時在 metrics dict 中新增 episode 長度供對照：

```python
"Episode_Length": float(n),
```

---

- 檔名改為 `05112trytrain_mujoco_td3.py`
- `gym.make()` 不要加 `reset_noise_scale` 參數（維持與 05111 相同）
- TensorBoard log 名稱改為 `05112_Advanced_control_1`
- 模型儲存路徑改為 `output/models/05112`
