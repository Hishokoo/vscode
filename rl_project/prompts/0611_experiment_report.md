# 0611 系列實驗報告：兩次訓練策略對比分析

## 背景

**任務**：InvertedPendulum-v4（MuJoCo），使用 TD3 演算法  
**目標**：讓模型在 delay=(1,2) 隨機化 + 外力擾動的環境下穩定生存，short_ratio < 15%（集次中 < 50 步的比例）  
**起點模型**：`05113.zip`，在固定 delay=1 下訓練 150K 步，ep_len_mean ≈ 1034

---

## 環境設定（兩次相同，固定不變）

```python
base_env = gym.make('InvertedPendulum-v4', max_episode_steps=2000)
env = AdvancedMotorWrapper(
    base_env,
    delay_random_range=(1, 2),
    disturbance_enable=True,
    disturbance_start_range=(50, 300),
    # 以下為可調參數（初始值）
    disturbance_probability=0.3,
    disturbance_magnitude_range=(0.1, 0.3),
    disturbance_duration_range=(2, 5),
    delay2_prob=0.5,           # delay=1 與 delay=2 各 50% 機率
)
```

**觀測空間**：5 維（cart_pos, pole_angle, cart_vel, pole_vel + last_real_action）  
**獎勵函數**：LQR 懲罰 + 穩態死區超級獎勵（clip 至 [-5, 10]），固定不變  
**訓練超參**：每輪 150K steps，batch_size=256，buffer_size=200000，sigma=0.2，全繼承自 zip

---

## 參數自動調整規則（兩次相同）

優先順序 D → A → C → B → E，每輪只套用第一個符合的：

| 規則 | 觸發條件 | 動作 |
|------|----------|------|
| D | critic_trend > 0.5（不穩定） | delay2_prob −0.05、disturbance_prob −0.05 |
| A | short_ratio > 0.4 | delay2_prob −0.05 |
| C | dist_ratio > 0.25 | magnitude 上限 −0.05、duration 上限 −1 |
| B | short_ratio ≤ 0.4 且 dist_ratio < 0.1 | disturbance_prob +0.05 |
| E | 以上均不符合 | 不變 |

**停止條件**：short_ratio < 0.15

## 關鍵觀察與假說

### 1. 課程學習造成初期崩壞
Stage 1 純 delay=2 訓練破壞了 05113 的 delay=1 能力，導致 Run 2 前 3 輪 short_ratio 飆至 66–86%（Run 1 同期為 34–44%）。Critic loss 在 06112 上升 95%，觸發規則 D。

### 2. 課程學習後期收斂更佳
Run 2 在 06119 達到 long_ratio 62.5%，優於 Run 1 最高的 56.6%。平均集長在 06117 達到 1000 步，顯示模型在適應期後更能穩定站立。

### 3. 兩次都無法突破 15% 的停止條件
short_ratio 最低值：Run 1 為 25.5%，Run 2 為 25.8%，差距極小。
可能原因：
- delay=2 的集次早死問題是結構性的，150K steps/輪 不足以完全解決
- replay buffer（200K）可能被 delay=1 的長存活集次佔據，稀釋了 delay=2 的學習信號
- disturbance_probability 在 Run 2 降至 0.20（規則 D 觸發），可能降低了環境難度但也減少了多樣性

### 4. 參數調整走向不同
- Run 1：只有 delay2_prob 被調整（0.5 → 0.35），disturbance 全程不變
- Run 2：兩者都被調整，disturbance_prob 從 0.30 降至 0.20（規則 D 觸發），delay2_prob 從 0.5 降至 0.30

---

## 待探討方向

1. **拉長每輪步數**（300K–500K）：給模型更多時間從 delay=2 早期崩壞中恢復
2. **Stage 1 延長**：純 delay=2 訓練到 ep_len_mean > 200 再進入混訓，確保模型真正學會 delay=2
3. **Replay buffer 分層**：強制 delay=1 與 delay=2 的樣本各佔 50%，避免長存活集次稀釋 delay=2 的學習
4. **漸進式混訓**：delay2_prob 從 0.1 逐步提高至 0.5，而非一開始就 50/50
5. **調整停止條件門檻**：15% 可能過於嚴格，先以 25% 為中繼目標
